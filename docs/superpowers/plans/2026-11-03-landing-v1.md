# Лендинг v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Статический двуязычный (RU/EN) лендинг начинающего AI-дизайнера из 7 блоков (раздел 6.5 research.md): быстрый, доступный, без cookie, с формой заявки и витриной готовых сайтов.

**Architecture:** Astro в режиме полностью статической сборки. Каждый блок — отдельный `.astro`-компонент, все тексты лежат в словарях `src/i18n/{ru,en}.ts`, данные витрины и контакты — в `src/data/`. Стили на нативном CSS (токены, scroll-driven animations, View Transitions) без CSS-фреймворка. Форма работает через Netlify Forms, без своего бэкенда. Хостинг — Netlify.

**Tech Stack:** Node 24, Astro (последняя стабильная ≥ 5), TypeScript, нативный CSS, `@fontsource-variable/onest` + `@fontsource-variable/jetbrains-mono`, Vitest, Playwright + `@axe-core/playwright`, `@lhci/cli`, Netlify.

**Spec:** [ТЗ: specs/2026-11-03-landing-design.md](../specs/2026-11-03-landing-design.md) — тексты, токены (включая `--accent-text: #2F4BE0` в светлой теме), элементы. Исходные данные: [research.md](../../../research.md): раздел 6 (концепция и структура); 5.1 и 5.5 п. 17–22 (UX, доступность, скорость); 3.3 палитра A; 1.11 шрифтовая пара №1.

**Решения, принятые мной при составлении плана** (можно оспорить):
- **Astro, а не чистый HTML.** Два языка и 7 блоков без компонентов превратились бы в копипаст. При этом Astro по умолчанию отдаёт 0 KB JS.
- **Netlify Forms.** Не нужен свой сервер, есть встроенная защита от спама.
- **Тексты в словарях.** Прямо сейчас на экране hero вариант №2 из 6.3. Цены, сроки и контакты стоят как плейсхолдеры `XXX`. Задача 9 не даст выпустить сайт, пока их не заменят.
- **Демо-сайты витрины (3–4 ниши) — отдельные проекты со своими планами.** Здесь только карточки со ссылками. У незаполненной ссылки статус «скоро».

## Global Constraints

- Языки: `ru` по умолчанию (без префикса в URL), `en` по адресу `/en/`.
- Тема: начальная берётся из `prefers-color-scheme`, переключатель запоминает выбор в `localStorage` (ключ `theme`, значения `light` | `dark`).
- Палитра A (3.3). Светлая: фон `#F0EEE9`, поверхность `#FFFFFF`, текст `#141414`, акцент `#3B5BFF`, доп. `#5C5A55`. Тёмная: фон `#0E0E10`, поверхность `#1A1A1E`, текст `#F0EEE9`, акцент `#C6FF3D`, доп. `#9A978F`.
- Шрифты: Onest (заголовки и текст), JetBrains Mono (только метки, цены, теги). Подгружаются локально, с `font-display: swap`.
- Контраст текста ≥ 4.5:1, у крупного ≥ 3:1, в обеих темах.
- Тап-зоны: кнопки и CTA ≥ 44×44 px, остальные интерактивные элементы ≥ 24×24 px. Фокус всегда видим и не перекрыт шапкой.
- Движение: все анимации живут только внутри `@media (prefers-reduced-motion: no-preference)`. Появление ≤ 300 мс, анимируются только `transform` и `opacity`. Без автокаруселей, автоплея и попапов.
- Без JS-зависимостей на клиенте, кроме скрипта темы (inline, < 1 KB).
- Без cookie и сторонних трекеров, поэтому нет и cookie-баннера. Аналитика опциональна: cookieless-скрипт из переменной `PUBLIC_ANALYTICS_SRC`.
- Core Web Vitals: LCP ≤ 2.5 с, INP ≤ 200 мс, CLS ≤ 0.1. Lighthouse mobile: Performance ≥ 90, Accessibility ≥ 95, Best Practices ≥ 95, SEO ≥ 95.
- Тексты без жаргона (LLM, RAG, MVP, стек) и без выдуманных цифр, рейтингов и счётчиков проектов.
- Главный CTA: «Хочу такой сайт» / «I want a site like this» → `#contact`. Второстепенный: «Подписаться на фишки» / «Follow for tips» → Instagram.
- Каналы: Instagram Direct (`https://ig.me/m/<ник>`), WhatsApp (`https://wa.me/<номер>`), Telegram (`https://t.me/<ник>`), email (`mailto:`).
- Минимальная ширина без горизонтального скролла — 320 px.

## Review Focus

1. **`localStorage` недоступен** (приватный режим, заблокированы данные сайта). Тема берётся из системы, переключатель работает в пределах сессии, ошибок в консоли нет. Тест в задаче 2.
2. **JS выключен или скрипт упал.** Весь контент виден: reveal-анимация не прячет блоки по умолчанию. Форма отправляется. Тест в задаче 8.
3. **Телефон 320 px и длинные русские слова** («адаптированный», «конфиденциальности»): нет горизонтального скролла на обоих языках. Тест в задаче 9.
4. **Только клавиатура.** Skip-link работает, фокус виден, при переходе по якорю цель не прячется под sticky-шапкой. Тест в задаче 3.
5. **Форма без согласия или с пустыми полями.** Нативная валидация блокирует отправку. Бот, заполнивший honeypot, отсекается. Тест в задаче 7.
